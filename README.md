# Баг в больнице — MVP

Короткая браузерная игра по концепции хакатона. Игрок пробует работу системного аналитика: узнаёт проблему, собирает требования, проектирует алгоритм и проверяет исправленную систему записи.

## Запуск

Откройте **index.html** в современном браузере. Установка, Node.js, сборка и интернет не нужны.

При желании можно запустить локальный сервер из папки проекта:

```powershell
python -m http.server 8080 --bind 127.0.0.1
```

Затем откройте http://localhost:8080.

## Что реализовано

- Три коротких коридора на одной основе: движение, прыжки, подвижные тележки, лужи, кнопки и двери. Возврат к контрольной точке без ограничения попыток.
- Вступление с программистом и четыре вопроса заказчику. Ошибки объясняются, правильные ответы формируют ТЗ.
- Конструктор схемы: палитра блоков, поле с ветками «Да/Нет», перетаскивание и установка блоков кликом. Пять действий, две ветки отказа и правило отмены записи.
- Проверка схемы с подсветкой ошибок. Отмена записи — отдельная ветка общего дерева с блоком освобождения времени. Есть отмена действия, сброс и сохранение расставленных блоков.
- Передача требований и алгоритма программисту.
- Пять работающих проверок: запись, конфликт времени, нерабочее время, отмена и повторная запись в освобождённый слот.
- Финал, сохранение этапа в localStorage, сенсорные кнопки и переход к отдельной механике для демонстрации.

Полное прохождение занимает примерно 5–8 минут. «Быстрый показ» под игрой начинает демонстрацию с выбранного этапа и сбрасывает предыдущий прогресс. Кнопка ↻ позволяет начать заново.

## Управление

| Действие | Клавиши |
| --- | --- |
| Движение | A / D или ← / → |
| Прыжок | Пробел, W или ↑ |
| Взаимодействие | E |

Используются физические коды клавиш, поэтому русская раскладка тоже работает. На телефоне есть экранные кнопки. Для алгоритма используются мышь, сенсорный экран или Tab и Enter.

В конструкторе перетащите блок слева в пунктирное место. Другой способ — выбрать блок и нажать на нужное место. Уже установленные блоки можно перетаскивать друг на друга для обмена. На ветке «Пациент отменяет запись?» разместите освобождение времени. Нажмите «Проверить решение», затем передайте схему программисту. Проверки на пяти пациентах доступны только на заключительном, четвёртом этапе миссии. На телефоне палитра и схема прокручиваются по горизонтали.

## Файлы

- `index.html`, `styles.css` — оболочка, интерфейсы и адаптивная вёрстка.
- `src/data.js` — диалоги, требования, блоки и тестовые сценарии.
- `src/logic.js` — проверка алгоритма и модель записи.
- `src/designer.js`, `designer.css` — интерактивная схема, палитра и проверка правильности сборки.
- `src/game.js` — Canvas-платформер с простой физикой и нарисованной кодом графикой.
- `src/app.js` — переходы, экраны, прогресс и сохранение.

Это демонстрационная модель одной даты и одного врача с часовыми слотами, работающего с 09:00 до 18:00. Проверки выполняются последовательно в памяти браузера. Для реальной системы нужна серверная реализация и атомарная защита от одновременного бронирования; в MVP бэкенда нет.
